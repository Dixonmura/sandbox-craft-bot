## [3.0.0] - 2026-03-15
### Added
- **Новый бот: VacancyTrackerBot** — полноценный модуль для поиска работы
    - Интеграция с API TrudVsem для получения актуальных вакансий
    - Гибкая система фильтров: регион, опыт, зарплата, ключевые слова
    - Ежедневные уведомления по расписанию с учётом часового пояса
    - Сохранение настроек в JSON-файлы для восстановления после перезапуска

- **Архитектурные улучшения**
    - Добавлен `SessionStateRepository` для чистого хранения состояний сессий
    - Реализовано автоматическое восстановление активных сессий при перезапуске
    - Созданы in-memory репозитории для надёжного тестирования
    - Добавлена постраничная пагинация вакансий (10 на страницу)

- **Тестирование**
    - Общее количество тестов: **365** (было 241)
    - Покрытие кода: **91%** (инструкции), **86%** (ветвления)
    - Добавлены интеграционные тесты для API и JSON-хранилищ

### Changed
- Полная переработка системы управления состояниями
- Улучшена обработка зависших диалогов (автоматическая очистка)
- Оптимизирована работа с Telegram API и внешними сервисами
- Обновлены тесты для всех слоёв приложения

### Fixed

- Решены проблемы с кодировкой в тестах
