# SandBoxCraftBot

Учебный Telegram-бот с тремя режимами:
- 🍅 **Pomodoro** — тайм-менеджмент по методу Pomodoro
- 🎬 **Movie Quiz** — угадай фильм по кадру
- 💼 **Vacancy Tracker** — персональный поиск работы (НОВИНКА!)

## Требования

- Java 21+
- Maven 3.8+
- Токен Telegram-бота
- (Опционально) Переменная окружения `BOT_TOKEN`

## Запуск

1. **Клонировать репозиторий**
   \`\`\`bash
   git clone https://gitlab.com/your-project/sandbox-multi-bot.git
   cd sandbox-multi-bot
   \`\`\`

2. **Установить токен бота**

   **Windows (CMD):**
   \`\`\`cmd
   set BOT_TOKEN=ваш_токен_бота
   \`\`\`

   **Windows (PowerShell):**
   \`\`\`powershell
   $env:BOT_TOKEN="ваш_токен_бота"
   \`\`\`

   **Linux/Mac:**
   \`\`\`bash
   export BOT_TOKEN=ваш_токен_бота
   \`\`\`

3. **Собрать и запустить**
   \`\`\`bash
   mvn clean package
   java -jar target/sandbox-multi-bot-3.0.0.jar
   \`\`\`

## Режимы работы

### 🍅 Pomodoro
Классический таймер для управления временем:
- Настраиваемые интервалы работы и отдыха
- Мотивационные картинки при смене фаз
- Статистика за 30 дней
- Ранжирование по количеству завершённых циклов

### 🎬 Movie Quiz
Киновикторина с угадыванием фильмов по кадрам:
- База из 50+ фильмов
- 4 варианта ответа на каждый вопрос
- Система рангов (от "Зрителя" до "Легенды экрана")
- Подсчёт очков в реальном времени

### 💼 Vacancy Tracker (Новинка! 🔥)
Персональный ассистент по поиску работы:
- **Гибкие фильтры**: регион, опыт, зарплата, ключевые слова
- **Интеграция с API TrudVsem** — реальные вакансии с госпортала
- **Ежедневные уведомления** в выбранное время (с учётом часового пояса)
- **Постраничный просмотр** — по 10 вакансий на экране
- **Автоматическое восстановление** настроек после перезапуска
- Сохранение данных в JSON-файлы

## Технические детали

### Архитектура
Проект построен по принципам **чистой архитектуры** с чётким разделением на слои:
- `presentation` — взаимодействие с Telegram API
- `core` — бизнес-логика и сервисы
- `data` — хранение данных (JSON-репозитории)

### Стек технологий
- **Java 21** — современный язык с новыми возможностями
- **TelegramBots** — библиотека для работы с Telegram API
- **Jackson** — сериализация/десериализация JSON
- **OkHttp** — HTTP-клиент для внешних API
- **JUnit 5 + AssertJ + Mockito** — тестирование
- **JaCoCo** — анализ покрытия кода
